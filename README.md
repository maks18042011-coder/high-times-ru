# High Times — русификатор

Неофициальный фанатский перевод визуальной новеллы **High Times**
(Yangyang Mobile) на русский язык.

| Что переведено | Строк |
|---|---|
| Диалоги и сюжет | 70 188 из 70 189 |
| Интерфейс, меню, настройки | 5 631 |
| Достижения | 469 |
| Предметы и рецепты | 239 |

## Установка (для игроков)

1. Скачайте `HighTimes_RU_v1.zip` со страницы
   [Releases](../../releases/latest) и распакуйте в любую папку.
2. Кликните правой кнопкой по `install_russian.ps1` и выберите
   **«Выполнить с помощью PowerShell»**. Укажите папку с игрой
   (там, где лежит `High Times.exe`) и подтвердите установку.

   Если пункта нет, откройте PowerShell в папке с архивом и выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File install_russian.ps1
   ```
3. Запустите игру: **Options → Language** → стрелкой выберите язык
   **«Русский»** (на месте Deutsch) → **Save Changes**.

Ручная установка без скрипта: скопируйте `localized.sq` и `vntext.sq`
из `HighTimes_RU\High Times_Data\StreamingAssets\SqlText\` в такую же
папку игры с заменой. Если папка
`%USERPROFILE%\AppData\LocalLow\Yangyang Mobile\High Times` существует,
положите эти же два файла и туда, иначе игра возьмёт старый текст из
кэша. Подробности — в [dist/ИНСТРУКЦИЯ.txt](dist/ИНСТРУКЦИЯ.txt).

**Откат:** `install_russian.ps1 -Uninstall` вернёт оригинальные файлы
из бэкапа, который скрипт делает при установке. Сохранения и прогресс
не затрагиваются.

### Как это работает

В игре нет русского языка, поэтому перевод записан в колонку немецкого
(`DE`) в текстовых базах игры. В выборе языка вместо Deutsch теперь
написано «Русский». Немецкий перевод при установке заменяется.

## Для переводчиков и разработчиков

Нужен Python 3.10+ (только стандартная библиотека) и своя копия игры.
В консоли Windows перед запуском скриптов выполните
`set PYTHONIOENCODING=utf-8` (PowerShell: `$env:PYTHONIOENCODING="utf-8"`),
иначе вывод с кириллицей и спецсимволами может упасть.

```
csv/                перевод: ui, achievements, items, pilot_menu
csv/dialogue/       диалоги, по файлу на персонажа (_index.csv — список)
extract.py          .sq → CSV (колонки id, file, context, source, target, status, max_len)
validate.py         проверка тегов, плейсхолдеров и длины строк
build.py            CSV → пропатченные .sq в work/build/
install.py          установка/откат сборки на КОПИЮ игры
progress.py         сколько переведено
glossary.md         правила перевода и написание имён
NOTES.md            подробный журнал: устройство игры, решения, найденные баги
CHECK.md            чек-лист ручной проверки в игре
dist/               установщик и инструкция для игроков
```

### Сборка

1. Скопируйте `localized.sq` и `vntext.sq` из
   `High Times_Data\StreamingAssets\SqlText\` своей игры в `work\SqlText\`.
2. Соберите базы:

   ```
   python build.py --input csv/ui.csv --input csv/achievements.csv --input csv/pilot_menu.csv --db localized.sq
   python build.py --input-dir csv/dialogue --db vntext.sq
   ```

   Результат появится в `work\build\plain\`. С флагом `--marker` каждая
   строка выводится как `[Ж]текст[rowid]`, так удобно искать её в CSV.
3. Установите на копию игры:

   ```
   python install.py --target-dir "путь\к\копии\игры"
   python install.py --target-dir "путь\к\копии\игры" --uninstall
   ```

   Чтобы скрипт никогда не писал в основную установку, задайте её путь
   в переменной окружения `HT_ORIGINAL_PATH`.

### Правила перевода

- Теги и плейсхолдеры (`{$mcName}`, `[i]`, `@[...]`, `\n`) копируются
  без изменений, это проверяет `validate.py`.
- Имена персонажей транслитерируются (Коннор, Кайл, Джоджо), бренды и
  названия рецептов остаются на английском. Полный список в
  [glossary.md](glossary.md).
- Статусы в CSV: `new` (не переведено), `translated`, `review`
  (спорное, оставлено на английском), `kept` (переводить не нужно).

## Известные проблемы

- Не переведена одна строка: `vntext.sq#46819` (`csv/dialogue/NARRATION.csv`).
- 72 строки в статусе `review` пока на английском.
- На некоторых экранах (иконки телефона, рецепты) кириллица может
  наезжать на соседние элементы — похоже, дело в метриках шрифта игры.

Исправления и предложения принимаются через Issues и Pull Requests.

## Правовое

Проект не связан с Yangyang Mobile. Все права на игру и оригинальный
текст принадлежат правообладателям. Для работы русификатора нужна
законно приобретённая копия игры.
