# Чек-лист ручной проверки — пилотный патч (главное меню + настройки)

Патч трогает только `localized.sq` (главное меню, настройки, диалоги
подтверждения, экран языка, кнопки загрузки/сохранения). Диалоги,
достижения, рецепты и магазин остались английскими — это ожидаемо, они не
входят в пилот.

## Как поставить

```
python build.py --input csv\pilot_menu.csv            # обычный патч
python build.py --input csv\pilot_menu.csv --marker    # версия с маркером [Ж]...[rowid]

python install.py --target-dir "путь\до\копии\игры"            # ставит обычный патч
python install.py --target-dir "путь\до\копии\игры" --marker   # ставит версию с маркером
```

`--target-dir` нужно указывать явно каждый раз — путей по умолчанию нет.
Скрипт откажется работать, если путь совпадает с оригинальной папкой игры,
и откажется, если папка не похожа на установку High Times (нет
`High Times.exe`).

Рекомендация: **сначала ставьте версию с `--marker`.** Каждая переведённая
строка выглядит как `[Ж]Новая игра[5]` — если видите квадратики вместо
`Ж` или кириллицы, это сразу говорит о проблеме со шрифтом, а число в `[]`
(rowid) помогает быстро найти конкретную строку в `csv/pilot_menu.csv`,
если что-то выглядит не так. После проверки маркерной версии ставьте
обычную (`install.py` без `--marker`) — это то, что увидит игрок.

## Как переключить игру на немецкий (там теперь русский)

1. Запустите игру, дождитесь главного меню (первый показ — обычно сразу
   меню; при повторных запусках игра может сначала проиграть вступительную
   сцену, которую нужно пройти вручную кликом/пробелом до меню).
2. **Options** → в строке **Language** нажимайте стрелку `>` до появления
   **Deutsch** (порядок: Default → English → 简体中文 → 繁體中文 → Deutsch → Français).
   Если ставили маркерную версию — сама строка языка тоже переведена и
   будет выглядеть как `[Ж]Русский[63]` вместо `Deutsch`.
3. **Save Changes** (после перевода — `[Ж]Применить[56]` / `Применить`).
4. Дальше весь текст, отмеченный в списке ниже, должен быть на русском.

## Что смотреть на каждом экране

### Главное меню
Ожидаемые надписи: Новая игра, Продолжить *(если есть сохранение)*,
Загрузить, Настройки, Экстра, Галерея, Выход, а также баннер
«Нажмите, чтобы продолжить» на самом первом экране запуска.

### Настройки → Gameplay
Геймплей, Темп текста, Автоскорость, Скорость курсора, Показать отладку,
Подсказки геймпада, Подсказки, Скип, Режим скипа (Классика/Мгновенно),
Не скипать непрочитанное.

### Настройки → Display
Экран, Режим экрана (Полный экран/Окно/Окно без рамки), Разрешение,
Качество текстур, Зум.

### Настройки → Audio
Звук, Общая громкость, Музыка, Эффекты, Голос, Озвучка, Другое,
В фоновом режиме, Общие.

### Настройки → Controls
Управление, Схема управления (Клавиатура/Xbox/PlayStation 4/PlayStation 5 —
**названия консолей остаются на английском, это правильно**), Действие,
Подать, Мусор, Скрыть UI, Клавиатура и мышь, Подтвердить, Загрузить,
Главное меню, (Удерж.) Ручной скип, Настройки, Далее,
Сохранить/Закрыть, Сохранить, (Скролл) Журнал, Скип, Контроллер Xbox.

### Диалоги подтверждения
- Выход в главное меню (со сцены/паузы) → «Вернуться в главное меню?
  Несохранённый прогресс будет потерян.»
- Выход из игры → «Выйти из игры?»
- Смена настроек без сохранения → «Настройки изменены!» /
  «Внимание: есть несохранённые изменения!»

### Язык
Строка **Language** → «Язык». Сам выбор языка: `English`/`中文`/`Français`
остаются нетронутыми (так и должно быть — так работают пикеры языка
везде, каждый язык подписан сам на себе), а `Deutsch` заменён на
«Русский» — это единственное сознательное исключение (объяснение в
`NOTES.md`, раздел «Перевод»).

### Пауза во время игры / загрузка-сохранение
Меню, Настройки, Управление, Выход, Загрузить, Сохранить,
«продолжить без сохранения», «сохранить в другом слоте».

## На что обращать внимание глазами

1. **Квадраты/пустые прямоугольники вместо букв** — признак отсутствия
   кириллицы в шрифте. В UI-шрифте (то, что выше) на Этапе 2 это уже
   проверено и работает; если увидите тофу — это неожиданность, сообщите.
2. **Обрезанные или наехавшие друг на друга кнопки** — уже наблюдалось на
   Этапе 2 с длинным тестовым маркером (наслаивались соседние пункты
   главного меню). Особо внимательно смотрите на:
   - **`ON`→`ВКЛ`, `Load`→`Загрузить` (2 места), `Save`→`Сохранить`** —
     эти 4 строки сознательно оставлены длиннее 40%-го лимита (в
     русском нет короткого аналога), они самые вероятные кандидаты на
     обрезку/наезд текста. Проверьте их в первую очередь.
   - Кнопки главного меню и вкладки настроек (Gameplay/Display/Audio/
     Controls) — там уже видели проблему с переполнением в тесте.
3. **Текст, вылезающий за границы окна/кнопки** (не обрезанный, а именно
   торчащий наружу) — отдельно от обрезки, тоже возможный симптом
   слишком длинного перевода.
4. **Разные шрифты в разных элементах экрана** — если где-то кириллица
   выглядит визуально иначе (другая гарнитура/жирность) относительно
   соседнего английского текста на том же экране — стоит сфотографировать
   и показать, это будет важно для Этапа 3.
5. **Межбуквенный интервал у кириллицы** — по коду (см. `NOTES.md`)
   у разработчиков есть спецкоррекция интервала конкретно для языка
   `"RU"`, которая не сработает, раз мы едем под видом `"DE"` — русский
   текст может казаться слегка "растянутым" по сравнению с тем, как он
   выглядел бы при официальной поддержке RU. Не баг, но стоит иметь в виду.

## Если что-то сломалось — откат

```
python install.py --target-dir "путь\до\копии\игры" --uninstall
```

Восстанавливает `StreamingAssets\SqlText\localized.sq` и кэш в
`AppData\LocalLow\Yangyang Mobile\High Times\localized.sq` из бэкапа,
сделанного при установке (папка `backup\install_<дата>\`). Ничего в
`State\`, `Log\` или `Player*.log` не трогается ни при установке, ни при
откате — прогресс и сохранения не затрагиваются.

**Важно:** кэш в `AppData\LocalLow\Yangyang Mobile\High Times\` общий для
любой копии игры с этим названием на компьютере, не только для той,
что вы указали в `--target-dir` (так работает Unity `PlayerPrefs`/
`persistentDataPath` — по имени издателя и игры, не по папке). Если на
машине есть/появится другая копия/оригинал High Times — она тоже увидит
пропатченный кэш до отката.
